# 110kV陶瓷基复合输电传感系统 · 状态监测与智能预警平台

> 江西省大学生创新创业训练计划项目（创新训练 · 省级重点项目）
> 江西省财经大学 · 软件与物联网工程学院 ｜ 项目负责人：董士波 ｜ 指导教师：王昊

## 项目简介

本项目面向 110kV 高压输电线路的状态感知与安全运维需求，将高性能陶瓷基复合材料与智能传感技术深度融合，实现线路的「自感知、自诊断、自优化」。本仓库为项目配套的**状态监测与智能预警平台前端原型**。

## 平台功能

| 模块 | 说明 |
|---|---|
| 多参量实时监测 | 导线温度、振动频率、轴向应变三通道同步曲线展示，支持图例切换 |
| 取能与储能状态 | 环形仪表实时显示取能效率与储能电压，含负荷高/低、微风等分工况指标 |
| 节点状态管理 | 按节点编号与杆塔区段集中监视取能方式、温度、振动与在线状态 |
| 告警与事件中心 | 紧急／重要／提示三级告警分类展示，配套处置进度时间线 |
| 智能预警 | 基于历史数据的异常趋势识别，提示温度越限、振动异常、覆冰趋势等风险 |

## 技术实现

- **纯前端单文件**，零第三方依赖、零构建步骤
- 图表与仪表盘均为**手写 SVG**，**无需联网**即可完整渲染（避免答辩现场网络故障）
- 原生 JavaScript 驱动，每 2 秒滚动刷新数据
- 响应式布局：桌面双栏 / 平板单栏 / 移动端纵向堆叠

## 本地运行

直接双击 `index.html` 即可打开；或在项目根目录启动任意静态服务器：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 关联技术

本平台对应项目五大研究内容中的「输电线路状态监测与智能预警平台开发」，与「无源自取能技术」「高压强电磁干扰下无线数据传输方案」共同构成从前端感知到后端智能分析的闭环链路。

当前平台为实验原型，主要用于功能演示与流程验证，尚未开展大规模真实线路部署。
